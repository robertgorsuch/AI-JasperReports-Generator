Jaspersoft Studio 10

Feature & Functionality Summary

Jaspersoft Studio is the official Eclipse-based desktop report designer for the JasperReports ecosystem. Version 10 is the design-time counterpart to JasperReports Library 7.x and JasperReports Server 10.0, and it produces JR7-native .jrxml reports. It replaced the legacy iReport Designer and is distributed both as a standalone RCP application and as an Eclipse plug-in.

Core Design Environment

  • WYSIWYG visual designer with drag-and-drop bands (Title, Page/Column Header & Footer, Group Header/Footer, Detail, Summary, Background, No-Data).
  • Multiple synchronized editors per report: visual Design canvas, raw Source (jrxml XML), and Preview (live render against real data).
  • Outline view (full report tree), Properties view (context-sensitive element attributes), Palette (all element/component types), and Report Inspector.
  • Project/workspace model — reports organized into JasperReports projects with classpath, resources, and build settings.
  • Snapping, alignment guides, rulers, z-order, element grouping, and styles management.

Data Connectivity

Data Adapters are reusable, portable connection definitions stored as .jrdax files:

  • JDBC (any driver — PostgreSQL, Oracle, SQL Server, MySQL, etc.)
  • JNDI, Spring/Bean, Hibernate / JPA
  • CSV, XML, XPath/XPath2, JSON / JSONQL, Excel (XLS/XLSX)
  • Empty / "one-record" adapters for static or component-only reports
  • Domain / Topic and JRS-backed adapters
  • Custom data-source providers via the extension API
  • Query Designer with SQL builder and support for SQL, HQL, JSON, XPath, MDX, and Domain/EJBQL query languages, plus a visual outline of result fields.
  • Dataset & field discovery — auto-introspects columns and maps them to Java field classes.

Report Building Blocks

  • Fields, Variables, Parameters with default-value expressions and calculation types (Sum, Average, Count, Highest/Lowest, etc.).
  • Expression Editor with autocomplete, a function library, and built-in functions (text, math, date/time, logical); expressions in Java, Groovy, or JavaScript.
  • Groups with headers/footers, subtotals, and group-based page/column breaks.
  • Styles — named styles, conditional styles, and external shared style templates (.jrtx) referenced across many reports.
  • Subreports and subdatasets for nested/embedded data.

Visualization & Components

  • Tables (with their own dataset), Lists, and Crosstabs (pivot tables with row/column groups, measures, totals).
  • JFreeChart-based charts (pie, bar, line, area, stacked, scatter, time series, etc.).
  • HTML5 / Highcharts charts and Fusion charts/maps/widgets (Pro / server-rendered).
  • Spider/radar charts, gauges, maps (Google/Fusion), barcodes & QR codes (barcode4j / ZXing).
  • Generic and custom components via the component extension framework.
  • Images, text fields, static text, frames, rectangles, lines, ellipses, hyperlinks, anchors, and bookmarks.

Server Integration (JasperReports Server)

  • Repository Explorer — connect to one or more JRS instances, browse the repository, and drag resources in/out.
  • Publish/deploy reports, images, fonts, resource bundles, and data adapters directly to the server.
  • Create and manage Input Controls (including query-backed and cascading) and run reports server-side from the IDE.
  • Edit server-side resources in place; supports JRS 10.0 REST connectivity and Pro/Enterprise features.

Output / Export Formats

PDF, HTML, XLS/XLSX, CSV, DOCX, PPTX, RTF, ODT/ODS, XML, plain text, and image formats — each with per-format export configuration (page setup, fonts, pagination, metadata).

Advanced / Developer Features

  • Internationalization — resource bundles, locale-aware formatting, and right-to-left support.
  • Custom fonts — font extensions (.jar) for embedded/PDF font handling.
  • Scriptlets and the full JasperReports extension API (custom components, query executers, data sources, functions).
  • Book reports — multi-part documents combining several report parts.
  • Virtualization and large-report handling; pagination control.
  • Maven/Gradle-friendly output; integrates into CI build pipelines.
  • Git/SCM friendly since the jrxml is plain XML.

Platform Notes for v10

  • Built on a current Eclipse 4.x / RCP platform; runs on Windows, macOS, and Linux.
  • Requires Java 11+ (aligned with JR7's runtime baseline).
  • Available in Community (open-source JR features) and Professional editions (adds Pro components — Highcharts/Fusion, HTML5 dashlets, advanced server features).
  • Produces JR7-native jrxml — the schema is not backward-compatible with the 6.x format; opening older reports triggers an upgrade.

Relation to this toolkit: the /jasper-deploy skill scripts the same lifecycle that Jaspersoft Studio performs interactively — scaffolding jrxml, compiling against the JR7 runtime, creating datasources/domains/style templates, and deploying to JRS 10.0 over REST. Studio is the GUI path; the scripts are the reproducible/CI path. The few artifacts that still benefit from Studio are single-CSV query-executer reports, multi-table Domains, and filter-group / input-control dashboards.
