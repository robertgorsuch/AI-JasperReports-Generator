Jaspersoft Community Edition

Detailed Feature, Architecture & Licensing Summary — JasperReports Library 7 & JasperReports Server (Community)

The Jaspersoft Community Edition is the free, open-source foundation of the Jaspersoft BI platform, now stewarded by Cloud Software Group (formerly TIBCO). It is the upstream, developer- oriented stream from which the licensed Commercial Edition is built. The community stack centers on three pieces: the JasperReports Library (the reporting engine), Jaspersoft Studio Community (the desktop report designer), and JasperReports Server Community (the web repository and runtime). It is licensed primarily under the GNU LGPL v3 (with the AGPL applying to parts of the community server), making it suitable for embedding within proprietary applications without releasing your own source.

JasperReports Library — the Engine

Report definition & lifecycle

  • Reports are defined in jrxml (XML), compiled to a binary .jasper, then filled with data to produce a JasperPrint document that is exported to a target format.
  • JR7-native schema in the version-7 line (not 6.x-compatible); fully programmable from Java.
  • Band-based layout: Title, Page/Column Header & Footer, Group Header/Footer, Detail, Summary, Background, No-Data.

Data sources

  • JDBC (any database), JavaBeans collections, Maps, CSV, XML / XPath, JSON / JSONQL, Excel, Hibernate / JPA, and empty data sources.
  • Pluggable query executers and custom data-source providers via the extension API.
  • Multiple query languages: SQL, HQL, XPath, JSON, MDX, EJBQL.

Building blocks & expressions

  • Parameters, Fields, Variables with calculation types (Sum, Average, Count, Highest/Lowest, etc.).
  • Expressions in Java, Groovy, or JavaScript; rich built-in function library.
  • Groups with subtotals and breaks; subreports and subdatasets; scriptlets and hooks.
  • Styles, conditional styles, and shared external style templates (.jrtx).

Components & visualization (open-source)

  • Tables, Lists, and Crosstabs (pivot tables with totals).
  • JFreeChart charts — pie, bar, line, area, stacked, scatter, time-series, etc.
  • Spider/radar charts, barcodes & QR codes (barcode4j / ZXing).
  • Images, text fields, frames, shapes, hyperlinks, anchors, and bookmarks.
  • Note: HTML5/Highcharts, Fusion charts, and map components are commercial-only and not part of CE.

Export formats

  • PDF, HTML, XLS/XLSX, CSV, DOCX, PPTX, RTF, ODT/ODS, XML, plain text, and image formats.
  • Per-exporter configuration (page setup, fonts, pagination, metadata, accessibility tagging for PDF).
  • Custom font extensions for embedded/PDF font handling and internationalization.

Jaspersoft Studio (Community)

  • Full Eclipse-based WYSIWYG designer — visual canvas, jrxml source view, and live preview.
  • Data Adapters (.jrdax), query designer, expression editor with autocomplete, outline & properties views.
  • Compile and preview locally; design tables, crosstabs, JFreeChart charts, barcodes, and subreports.
  • Can connect to and publish reports to a JasperReports Server (community or commercial).
  • Identical authoring experience to the Pro Studio except the Pro-only components (HTML5/Fusion/maps).

JasperReports Server (Community)

  • Repository — web-based store for reports, data sources, images, fonts, and resources, organized in folders.
  • Run & export reports interactively or via the REST v2 API in any supported format.
  • Basic scheduling — recurring/triggered report jobs delivered to the repository or email.
  • Input controls — parameterized reports with prompts (single, select, query-backed).
  • Basic role-based security — users, roles, and repository permissions (no multi-tenant organizations).
  • JDBC and file data sources; deploy/compile jrxml server-side.

Not in the community server (commercial-only)

  • Ad Hoc Editor (self-service authoring) and Domains (semantic layer).
  • Interactive dashboards designer and the interactive HTML5 viewer (sort/filter/save state).
  • OLAP / Mondrian analysis and in-memory acceleration.
  • Multi-tenancy (organizations), LDAP/SSO/SAML, attribute & data-level security, auditing, HA/clustering.
  • Visualize.js embedding framework and Pro visualization components.
  • Jaspersoft AI Analyst and vendor support/SLA.

Developer & Embedding Story

  • Pure-Java engine — embed the JasperReports Library directly in any JVM application (Spring, Jakarta EE, desktop) with a few jars.
  • Programmatic API: JasperCompileManager, JasperFillManager, JasperExportManager, and the export configuration classes.
  • Extension framework — add custom components, fonts, query executers, data sources, and functions.
  • JasperReports IO — a REST and JavaScript (jrio.js) layer for cloud-native, language-agnostic rendering and embedding.
  • Build-tool friendly — artifacts on Maven Central; jrxml is plain XML, so reports are Git/SCM friendly and CI-pipeline ready.

Licensing & Support

  • JasperReports Library: LGPL v3 — can be embedded in proprietary/commercial software without open-sourcing your application.
  • JasperReports Server (CE): AGPL v3 — network-use copyleft; review obligations before SaaS distribution (the commercial license removes AGPL constraints).
  • Support: community forums, public documentation, and source on GitHub — no vendor SLA, hotfixes, or indemnification (those are commercial-only).
  • Cost: free to download and use; you self-build, self-host, and self-maintain.
