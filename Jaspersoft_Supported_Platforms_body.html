Jaspersoft — Supported Platforms

Operating Systems, Java, App Servers, Databases, Browsers, Cloud & Embedding — Version 10

This document summarizes the platforms across which the Jaspersoft product family runs — JasperReports Server, Jaspersoft Studio (desktop), Jaspersoft Web Studio, the JasperReports Library, and JasperReports IO. Exact certified versions are release-specific; for a production commitment, pin the matrix from the Jaspersoft Platform Support Guide / Release Notes for the exact v10 build. The supported categories below are stable across the version-10 line.

Operating Systems

ComponentSupported operating systems
JasperReports ServerWindows Server; major Linux distros (RHEL / CentOS / Rocky, Ubuntu, SUSE); other 64-bit JVM-capable Unix.
Jaspersoft Studio (desktop)Windows, macOS, Linux (Eclipse / RCP, 64-bit).
Jaspersoft Web StudioRuns in the browser inside JasperReports Server — OS-independent on the client.
JasperReports Library / IOAny 64-bit OS with a supported JVM.

Java Runtime

  • Java 11+ is the baseline for the version-10 / JasperReports 7 line (server, Studio, and library).
  • Older 6.x lines ran on Java 8; each release certifies specific OpenJDK / Oracle JDK builds.

Application Servers (JasperReports Server)

TierApplication servers
Bundled / primaryApache Tomcat (ships with the installer).
Also supported (commercial)WildFly / JBoss EAP, Oracle WebLogic, IBM WebSphere.

Repository (Metadata) Databases

JasperReports Server stores its repository, users, roles, and configuration in one of:

  • PostgreSQL (default / bundled)
  • MySQL / MariaDB
  • Oracle Database
  • Microsoft SQL Server
  • IBM DB2

Reporting Data Sources (JDBC & Beyond)

CategoryPlatforms
Relational (JDBC)PostgreSQL, MySQL / MariaDB, Oracle, SQL Server, DB2 — and any JDBC-compliant database.
Cloud data warehousesAmazon Redshift, Snowflake, Google BigQuery, Azure Synapse, and the Actian Data Platform.
Big data / NoSQLApache Hive, Impala, Spark SQL, Cassandra, MongoDB, and Hadoop-family connectors (commercial connector set).
File / API / virtualCSV, XML / XPath, JSON / JSONQL, Excel, JavaBeans; plus JNDI, Bean / Spring, and virtual data sources.

Web Browsers (Server UI, Viewers, Web Studio)

  • Google Chrome, Mozilla Firefox, Microsoft Edge, Apple Safari — current / recent versions.
  • Internet Explorer is dropped in modern releases.

Cloud & Container Deployment

  • Amazon AWS and Microsoft Azure marketplace images (BYOL / hourly / managed).
  • Docker containers and Kubernetes orchestration — especially JasperReports IO for cloud-native deployments.
  • Self-managed on any IaaS that meets the OS / JVM matrix.

Embedding & Client Platforms

  • Visualize.js (commercial) — embed reports/dashboards into any web app; React / Angular components.
  • JasperReports IO REST + jrio.js — language-agnostic embedding (Node, Python, .NET, PHP, …).
  • REST v2 API — callable from any HTTP-capable platform or language.

Output / Rendering Targets

PDF, HTML / HTML5, XLS / XLSX, CSV, DOCX, PPTX, RTF, ODT / ODS, XML, plain text, and image formats — consumable on any device or OS.

Certified vs. Compatible

  • Certified — formally tested and supported under your commercial license for a given release.
  • Compatible — works in practice but is not formally certified.
  • For a production commitment, pin the exact certified matrix from the v10 Platform Support Guide.
Relation to this toolkit: the local stack reflects a typical certified profile — jasperserver-pro 10.0 on Apache Tomcat, Java 11, with a PostgreSQL repository and reporting against PostgreSQL and the Actian Data Platform (driven by the admiral skill).
