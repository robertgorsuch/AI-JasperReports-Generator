Jaspersoft Copilot — Preflight Module

Developer specification for the shared entitlement / metering / guardrails chokepoint

Companion to the Product Brief and Licensing & Metering Scope · Owner: Robert Gorsuch · 2026-06-26 · Status: stub for review

1. Purpose

The preflight module is the single place every jasper-deploy script passes through before it does work. It exists so the four cross-cutting product concerns — entitlement, connection profiles, metering, and guardrails — are applied uniformly instead of being re-implemented (and drifting) across ~25 scripts.

It is the critical path identified in the licensing scope: get this interface right, refactor the scripts to source it, and all four concerns land together. There are two implementations sharing one on-disk contract:

FileConsumed by
copilot/preflight/Entitlement.psm1PowerShell scripts — deploy_report.ps1, compose_dashboard.ps1, create_domain.ps1, …
copilot/preflight/entitlement.pyPython scaffolders — scaffold_jrxml.py, gen_dashboard.py, scaffold_domain_schema.py, …

Both read the same layout under ~/.jaspersoft-copilot/ (config.json, usage.ndjson, audit.ndjson) and the same tier→feature map, so a PowerShell deploy step and a Python scaffold step bill and audit consistently.

4. Billable events

Each event is already an API call the toolkit makes — metering is instrumentation at the existing chokepoint, not new product surface. Events are idempotent per (resourceUri, event, day) so a retried deploy does not double-bill.

5. Wiring an existing script

The four concerns added to a script in the order they execute:

Import-Module "$PSScriptRoot/../copilot/preflight/Entitlement.psm1"

Assert-CopilotEntitlement -Feature 'report.deploy'          # 1. gate (throws if not entitled)
$p = Get-CopilotProfile                                      # 2. profile (not hardcoded localhost:8081)

Invoke-CopilotMutation -Action 'report.deploy' -ResourceUri $TargetUri {   # 4. dry-run + audit + confirm
    # existing REST PUT, using $p.jrsUrl and Resolve-CopilotSecret $p.jrsSecretRef
}

Write-CopilotUsage -Event 'report.deployed' -ResourceUri $TargetUri        # 3. meter
