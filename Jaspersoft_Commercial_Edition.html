Jaspersoft Commercial Edition

Detailed Feature, Architecture & Licensing Summary — JasperReports Server 10 (Professional / Enterprise)

Jaspersoft is a Business Intelligence and embedded-analytics platform now owned by Cloud Software Group (formerly TIBCO Software). It ships in two streams: an open-source Community Edition (the JasperReports Library and the basic JasperReports Server) and the Commercial Edition — a licensed, supported product sold in Professional and Enterprise tiers (often labelled "Jaspersoft Commercial" or "JasperReports Server PRO"). The Commercial Edition is built for production, multi-tenant, and OEM/embedded deployments where reliability, scale, security, and a no-code business-user experience matter. This document summarizes what the commercial product adds over the community core.

The Commercial Edition is available on-premise, as a self-managed cloud install, and via the AWS and Microsoft Azure marketplaces (BYOL or hourly/managed images).

Core Commercial-Only Capabilities

Ad Hoc Editor (self-service authoring)

  • Browser-based, no-code designer letting business users build tables, crosstabs, and charts by drag-and-drop.
  • Works over Topics (a jrxml query), Domains (the semantic layer), or OLAP connections.
  • Live filtering, sorting, grouping, calculated fields/measures, and conditional formatting without writing SQL.
  • Saved Ad Hoc Views become reusable building blocks for reports and dashboards.

Domains — the semantic layer

  • A business-friendly model that maps physical tables/joins to friendly field names, sets, filters, and security rules.
  • Multi-table Domains with joins, derived tables, calculated fields, and presentation groupings.
  • Row- and column-level security expressed in the Domain and enforced per user/role/tenant.
  • Decouples report authors from the database schema — the basis for governed self-service.

Interactive Dashboards

  • Drag-and-drop Dashboard Designer combining reports, Ad Hoc views, input controls, filters, text, web content, and images.
  • Filter groups and cross-dashlet wiring so one control drives multiple tiles.
  • HTML5 interactive viewer with drill-down, in-place sorting, and export of the whole dashboard.

Interactive HTML5 Report Viewer

  • In-viewer column sort, filter, conditional formatting, and resize; floating headers; in-place chart interactivity.
  • Save the manipulated state as a new report — a feature absent from the community viewer.

OLAP & In-Memory Analysis

  • Mondrian ROLAP engine with MDX queries, cubes, dimensions, and an analysis-view designer.
  • Jaspersoft OLAP client for slice-and-dice pivoting; XML/A connectivity to external OLAP servers.
  • In-memory acceleration (Domain-based) for fast ad hoc over large datasets.

Visualization & Pro Components

  • HTML5 charts (Highcharts) — rich interactive column/bar/line/area/scatter/heatmap/treemap/solid-gauge types.
  • Fusion charts, gauges, widgets, and maps (FusionMaps choropleth/geographic).
  • Advanced map components (Google Maps, Fusion, geo-mapping).
  • These Pro components render server-side and ship only with the commercial product.

Embedding & Developer APIs (OEM strength)

  • Visualize.js — a JavaScript framework to embed reports, dashboards, Ad Hoc views, and input controls into any web app with full programmatic control (events, parameters, drill, export). Commercial-only.
  • REST v2 API — comprehensive endpoints for resources, report execution (sync & async), input controls, jobs, permissions, users/roles/organizations, export/import, and domains.
  • Embedded web frameworks — React/Angular components and an iframe/SSO embedding model.
  • White-labelling & theming — full CSS theme override of the web UI per organization for OEM branding.
  • OEM/redistribution licensing — commercial terms specifically for embedding Jaspersoft inside a product you ship to customers.

Multi-Tenancy & Security (Enterprise)

  • Organizations (tenants) — hierarchical tenant isolation of repository, users, roles, and themes; the foundation for SaaS / multi-customer hosting.
  • Fine-grained repository permissions (administer / read+write / read-only / execute-only) per user and role.
  • Attribute-based security — server/org/user attributes usable in datasource URLs, queries, and Domain security expressions for data-level isolation.
  • Pluggable authentication: LDAP/Active Directory, SSO, SAML, OAuth, CAS, Kerberos, and external auth via Spring Security.
  • Profile attributes, password policies, and data-level (row/column) security.

Scheduling, Distribution & Alerting

  • Report Scheduler — recurring/triggered/one-off jobs delivered to the repository, FTP, or email in multiple formats.
  • Data-driven alerts — fire notifications when a watched report value crosses a threshold.
  • Saved report options (named input-control value sets) and parameterized scheduled runs.

Administration, Operations & Scale (Enterprise)

  • Auditing & monitoring — track logins, report runs, resource changes; built-in audit reports and a usage dashboard.
  • High availability & clustering — load-balanced multi-node deployments with a shared repository.
  • Diagnostic & log collectors, JMX metrics, and cache management.
  • Import/Export & promotion — package repository content for dev→test→prod migration and backup.
  • Tunable virtualization for very large reports and concurrent fills.

AI & Modern Analytics

  • Jaspersoft AI Analyst — a natural-language / generative-AI layer over a governed semantic model that lets business users ask questions and get answers, charts, and narratives.
  • Semantic-model-driven metrics and dimensions feeding both classic reporting and the AI experience.

Data Connectivity (Commercial extras)

  • All community JDBC/JNDI/Bean/CSV/XML/JSON adapters, plus commercial connectors and the Domain/virtual data sources.
  • Virtual data sources — combine multiple data sources behind one Domain.
  • Big-data & cloud connectors (e.g. Hadoop/Hive, cloud warehouses) available through the commercial driver set.
  • AWS RDS/Redshift-aware datasource descriptors.

Support, Licensing & Packaging

  • Commercial license (subscription/term) with vendor technical support, SLAs, hotfixes, and maintenance updates.
  • Jaspersoft Studio Professional design-time client included for authoring Pro components and connecting to the commercial server.
  • Per-core / per-CPU, per-user, or OEM redistribution licensing models.
  • Marketplace images (AWS / Azure) for fast provisioning; on-prem installers for Windows and Linux.
  • Indemnification and certified, tested release builds (vs. self-built community artifacts).
