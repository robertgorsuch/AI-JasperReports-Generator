JasperReports Server

Detailed Feature & Functionality Summary — Version 10

JasperReports Server is the web-based reporting and analytics server at the center of the Jaspersoft platform. It is a Java web application (built on Spring, deployed in Apache Tomcat) that stores, runs, schedules, secures, and distributes reports, dashboards, and analytic views. It builds on the open-source JasperReports Library engine and exposes everything through a browser UI, a comprehensive REST v2 API, and the Visualize.js embedding framework. It ships in an open-source Community edition and a licensed Commercial edition (Professional / Enterprise); this summary covers the full feature surface, noting where capabilities are commercial-only.

Architecture & Platform

  • Java web application on the Spring Framework + Spring Security, packaged as a WAR and run in Apache Tomcat (bundled or standalone).
  • A metadata repository database (PostgreSQL, MySQL, Oracle, SQL Server, etc.) stores all resources, users, roles, and configuration.
  • JasperReports Library embedded as the fill/compile/export engine; Mondrian embedded as the ROLAP engine (commercial).
  • Runs on Windows and Linux, on-premise or in the cloud; available as AWS and Azure marketplace images (commercial).
  • Horizontally scalable with load-balanced clustering and a shared repository (commercial/Enterprise).

The Repository

  • A hierarchical folder store for every resource type: report units, jrxml files, data sources, images, fonts, resource bundles, style templates, input controls, queries, Domains, OLAP schemas, dashboards, Ad Hoc views, and themes.
  • Resources are addressed by repository URI (e.g. /reports/geocoder/county_summary) and versioned with optimistic locking.
  • Browse, search, organize, copy/move, and permission resources through the UI or REST.
  • Import / Export service packages repository content (catalogs) for backup and dev→test→prod promotion across servers.
  • Reference resources (a report referencing a data source, a dashboard referencing reports) are tracked, with in-use protection against deleting a referenced resource.

Reporting

Report execution & rendering

  • Server-side compile of jrxml on deploy/first run, then fill against the report's data source and export.
  • Synchronous run (/rest_v2/reports/{uri}.{fmt}) and asynchronous execution (reportExecutions: submit → poll status → download) for large/slow fills.
  • Export to PDF, HTML, XLS/XLSX, CSV, DOCX, PPTX, RTF, ODT/ODS, XML, and image formats.
  • Interactive HTML5 viewer (commercial) — in-place column sort, filter, conditional formatting, resize, floating headers, and save-as-new-report.

Parameters & input controls

  • Input controls prompt users for report parameters: single value (text/number/date/datetime), single/multi select, boolean, and query-backed lists.
  • Cascading input controls — a child control's options filter by the parent's selection.
  • Saved report options — named sets of input-control values stored beside a report for one-click reruns.

Self-Service Analytics (Commercial)

Ad Hoc Editor

  • No-code, browser-based designer for tables, crosstabs, and charts by drag-and-drop.
  • Built over Topics (a jrxml query), Domains (semantic layer), or OLAP connections.
  • Live filter/sort/group, calculated fields and measures, and conditional formatting — no SQL required.
  • Saved Ad Hoc Views are reusable in reports and dashboards.

Domains — semantic layer

  • A governed, business-friendly model mapping physical tables/joins to friendly field names, sets, and filters.
  • Multi-table joins, derived tables, and calculated fields; presentation groupings for the designer.
  • Row- and column-level security enforced per user/role/tenant via security expressions and profile attributes.

Dashboards

  • Drag-and-drop Dashboard Designer combining reports, Ad Hoc views, input controls, filters, text, images, and web content.
  • Filter groups and cross-dashlet wiring so one control drives multiple tiles.
  • Interactive HTML5 dashboard viewer with per-tile drill-down and export.

OLAP & in-memory analysis

  • Mondrian ROLAP with MDX, cubes, dimensions, and an analysis-view designer; XML/A connectivity to external OLAP servers.
  • In-memory acceleration for fast Ad Hoc over large datasets.

Data Connectivity

  • JDBC data sources (any driver), JNDI, Bean/Spring, and file-based (CSV/XML/JSON/Excel) data adapters.
  • Virtual data sources (commercial) — combine multiple sources behind one Domain.
  • AWS (RDS/Redshift-aware) descriptors and big-data/cloud-warehouse connectors (commercial).
  • Data sources are first-class repository resources, reusable across many reports.

Scheduling, Distribution & Alerting

  • Report Scheduler — one-off, recurring (minute/hour/day/week), or calendar/trigger-based jobs.
  • Delivery to the repository, FTP, or email in multiple formats simultaneously, with parameterized values baked in.
  • Data-driven alerts (commercial) — notify when a watched report value crosses a threshold.
  • Job management UI and REST CRUD for listing, editing, and removing scheduled jobs.

Security & Multi-Tenancy

  • Authentication: built-in users; pluggable LDAP/Active Directory, SSO, SAML, OAuth, CAS, Kerberos via Spring Security (external auth is commercial-grade).
  • Role-based access — users and roles with fine-grained repository permissions (administer / read+write / read-only / execute-only) per resource.
  • Organizations (tenants) (commercial/Enterprise) — hierarchical tenant isolation of repository, users, roles, and themes for SaaS/multi-customer hosting.
  • Attribute-based security — server/org/user attributes used in data-source URLs, queries, and Domain security for data-level isolation.
  • Row- and column-level data security, password policies, and profile attributes.

Administration & Operations

  • User, role, and organization management UI and REST services.
  • Auditing & monitoring (commercial) — track logins, report runs, and resource changes; built-in audit reports and a usage/analysis dashboard.
  • Diagnostics — log collectors, JMX metrics, and a server-state/diagnostic snapshot.
  • Cache management — query/Ad Hoc result caches with REST invalidation.
  • Server-wide settings, themes, and attribute configuration.
  • High availability & clustering (commercial/Enterprise) for load-balanced, fault-tolerant deployments.

UI Themes & White-Labelling

  • The web UI is restyled via CSS theme folders (key file overrides_custom.css) under a Themes folder.
  • Themes are activated per organization and take effect immediately (no restart); previewable with a &theme= URL parameter.
  • Full white-labelling for OEM/embedded deployments — banner, login, buttons, tables, fonts, and images.

APIs & Embedding

  • REST v2 API — comprehensive coverage: resources, report execution (sync/async), input controls & their values, jobs, alerts, permissions, attributes, users/roles/organizations, domains, queryExecutor, options, caches, export/import, and themes. Discoverable via the live application.wadl.
  • Visualize.js (commercial) — JavaScript framework to embed reports, dashboards, Ad Hoc views, and input controls into any web app with full event/parameter/drill/export control and CORS domain-whitelisting.
  • Embedded web components for React/Angular and an iframe/SSO embedding model.
  • Legacy SOAP and the older REST v1 are present for compatibility; REST v2 is the source of truth.

AI & Modern Analytics (Commercial)

  • Jaspersoft AI Analyst — a natural-language / generative-AI experience over a governed semantic model; business users ask questions and receive answers, charts, and narratives.
  • Semantic-model-driven metrics and dimensions shared between classic reporting and the AI layer.
